# Оптимизация компонентов для Google PageSpeed

## 🚀 Внесенные оптимизации

### 1. **Оптимизация изображений**

#### ProductCard.vue
- ✅ **WebP формат** - уменьшение размера на 25-35%
- ✅ **Lazy loading** - загрузка только при необходимости
- ✅ **Responsive sizes** - правильные размеры для разных экранов
- ✅ **Placeholder** - показ плейсхолдера во время загрузки
- ✅ **Оптимизированное качество** - 75% вместо 80%
- ✅ **Fetchpriority="low"** - низкий приоритет для карточек
- ✅ **Описательные alt-теги** - улучшение SEO и доступности

#### ProductInfo.vue (Hero секция)
- ✅ **Priority loading** - высокий приоритет для hero изображения
- ✅ **Fetchpriority="high"** - приоритетная загрузка
- ✅ **WebP формат** - оптимизированный формат
- ✅ **Качество 85%** - баланс между качеством и размером
- ✅ **Placeholder** - плавная загрузка

#### Страница продукта ([id].vue)
- ✅ **Основное изображение** - priority + fetchpriority="high"
- ✅ **Миниатюры** - fetchpriority="low" + качество 60%
- ✅ **Описательные alt-теги** - с названием товара
- ✅ **Оптимизированные размеры** - точные размеры для каждого элемента

#### FullscreenView.vue
- ✅ **Основное изображение** - priority + качество 90%
- ✅ **Миниатюры** - fetchpriority="low" + качество 60%
- ✅ **Описательные alt-теги** - для всех изображений

#### AppHeader.vue
- ✅ **Логотип** - loading="eager" + fetchpriority="high"
- ✅ **Alt-тег** - описательный текст для логотипа

## 🎯 Ключевые принципы оптимизации

### 1. **Приоритизация ресурсов**
- Hero изображения: `priority` + `fetchpriority="high"`
- Карточки товаров: `fetchpriority="low"`
- Миниатюры: `fetchpriority="low"`

### 2. **Оптимизация форматов**
- WebP для всех изображений
- Качество 60-85% в зависимости от важности
- Lazy loading для не-критических изображений

### 3. **SEO улучшения**
- Описательные alt-теги
- Правильные мета-теги
- Структурированные данные

### 4. **Производительность**
- Responsive sizes для всех изображений
- Placeholder изображения
- Оптимизированные размеры

## 🔧 Рекомендации для дальнейшей оптимизации

### 1. **Серверные оптимизации**
- Включить gzip сжатие
